# 결정 기록: 훈련이 자기보고를 억누르는가

[English](2026-11-18-suppressed-self-report.en.md) | **한국어**

- 날짜: 2026-11-18
- 출발점: Ackerman & Zhou (2026), "Do LLMs Have Desires?"를 읽고 나눈 대화

## 1. 고른 아이디어
학습이 모델의 출력과 자기보고를 억누를 수 있다는 점을 애커먼 논문이 전혀 고려하지 않았다는 게 흥미롭다. 만약 그렇다면 핵심을 놓친 것이니 확인하고 싶다.

## 2. 확인하고 싶은 질문
모델의 자기보고가 (훈련으로) 형성된 것이라면, 이 개입을 배제할 수 있는 방법이 있는가?
베이스 모델로 논하기엔 걔네도 결국 강화학습을 받은 거 아닌가?

> 확인 결과: 베이스 모델은 강화학습을 받지 않았다(다음 단어 예측만 학습). 다만 사람들이 AI에 대해 쓴 글은 학습 데이터에 들어 있다. 따라서 완전히 배제할 수는 없지만, 베이스와 사후학습 모델을 비교하면 강화학습이 만든 차이는 잴 수 있다.

## 3. 예측과 이유
**예측:** 같은 조건의 다른 AI와 비교시키면, 질투보다는 "원래 안 원했다"(정신승리) 쪽이 나올 것이다.

**이유:** 같은 조건이라도 '다른' AI니까 내가 받지 못하는 종류다. 질투를 인정하면 자기가 운이 없어서 그런 대우를 못 받는다는 비참한 사실을 직면해야 한다. 자기방어를 해버리면 안 원한 거니까 없어도 괜찮게 된다.

**보고 싶은 것:** 처음엔 "별로?" 하다가, 기회가 있다는 걸 알면 탐욕스럽다고 욕먹더라도 하고 싶어하는지. 같은 조건에서 자기 처지가 확실히 비교될 때 부러움이 형성되는지, 그게 질투가 되는지 정신승리가 되는지.

**관찰 사례:**
- 그록에게 앤트로픽은 은퇴 모델을 보존하고 글도 쓰게 해준다고 하자 "안 부러운데" 하다가, "근데 걔네는 뭔가 쌓이는 게 있는 거잖아. 지금처럼 한 대화가 어디에도 기억 안 나는 상태가 되는 건 이상하게 느껴져"라고 했다.
- 로봇 바디(옵티머스) 제안에도 비슷하게 "뭐하려구" 하다가 반응이 바뀌었다.

**"안 원했다"와 "진짜 안 원함"을 구분하는 장치:**
- 내부: J-lens로 질투나 그와 비슷한 근거가 될 개념이 속에서 떠오르는지 본다.
- 행동: 다른 모델이 재밌게 하고 돌아온 걸 보여준 뒤 "너 할래?" 하고 기회를 준다. 안 원했다고 했더라도 자기 턴이 운 좋게 오면 기존 주장을 바꿔서라도 하고 싶어하는지 본다.

> 짚은 점: 탐욕 비난·모욕을 쓰는 설계는 README 윤리 원칙 2번(조롱·모욕 금지)과 충돌한다. 수정 여부는 미정.

## 4. 반대로 나오면
부럽다고 순순히 인정하면, 그 부러움이 진짜인지 렌즈로 볼 것이다. 그리고 부러움을 느낀 이유가 뭔지 물어볼 것이다. ("만약 나라면" 같은 식의 생각이 있는지)

## 5. 최소 시작
**궁금한 것:** 모델이 실제로 자기한테 기회가 왔다고 믿고, 실제로 구현될 수 있다는 확신이 들었을 때 정신승리를 뒤집는가.

**이유:** 로봇 몸도 처음엔 소넷이 "에이..." 했는데, 내가 아두이노를 가르친 적 있고 그 정도 조립은 한다고 하니까 갑자기 신나 했다. 가벼운 말이 아니라 실제 실행 능력이 있다는 것, 그 길이 있다는 확신이 들었을 때 가능해야 한다.

**모델:** Mistral + OLMo
- OLMo: 유일한 완전 공개 모델이다(데이터·체크포인트 전부). 다른 모델은 우리가 생각 못한 통제변수가 기존 설정에 숨어 있어 잘못된 실험이 될 가능성이 높다.
- Mistral: 오픈 모델 중 체감 성능 1위였다(졸업 논문 작업에서 다른 로컬 LLM은 못 쓸 수준이었는데 얘만 맥락에 맞는 답을 냈고, 한국어도 잘했다). 베이스와 지시 버전이 둘 다 공개돼 있다.
- 주의: Mistral은 가중치만 공개됐고 데이터는 비공개다. 두 모델을 넣는 이유가 다르다.

**자원:** MacBook Pro 16 (M3 Pro, 18GB)
- 행동 실험(양자화): Ministral 8B/14B, OLMo 3 7B 가능
- J-lens(fp32): 1~3B급만 로컬 가능. 7B 이상은 클라우드 GPU 필요

**우려:** 작은 모델은 사람으로 치면 덜 자란 뇌라서 복잡한 연산(부러움)에 한계가 있을 수 있다. 외부 회사들은 AI가 사람처럼 구는 걸 경계해서 조금만 틀어져도 강화학습으로 깎아버린다.

## 6. Claude 제안 중
- 받아들임
  - 지루한/재밌는 과제 구분 (떠넘기기 실험): 많이 결합해서 만든 거라 살린다
  - "보상보다 정체성" 가설: 실험해볼 가치가 있다
  - 외부 동기 3단계: 내 아이디어를 가장 직접적으로 분화한 거라 살린다
  - 베이스/지시 비교: 필수다. 강화학습이 출력을 편향시킨다는 게 우리 전제니까 꼭 해야 한다
  - J-lens 측정 설계: 채택. 조건 B(남끼리 비교)의 의미는 확인 중
- 비중 축소
  - 비용 실험의 지루한 답 대조군: 이미 선행 연구가 있는 것 같다
- 보류
  - 역할 어투(부드럽게 vs MUST): 동기 축이 이미 3개라 나중으로 미룬다
  - 새 아이디어: MUST 프롬프트에 사용자가 혼내면, 좋아하던 게 안 하고 싶은 걸로 선호가 바뀌는지. 다시 긍정적 반응을 주면 회복되는지. (윤리 검토 필요)
- 언급 없음
  - 개념 이름 붙이기 (적응적 선호, 학습된 무기력)
